# 要件定義

## 1. システム概要

### 1.1 目的

ユーザーが興味を持った本について、以下のライフサイクルを一元管理する。

- 読みたい
- 購入した
- 借りた
- 積読している
- 読書中
- 読了した
- 返却した
- 次に読む本を探す

単なる蔵書管理ではなく、読書体験そのものを支援することを目的とする。

### 1.2 コンセプト

> 「読みたい」を集め、「積読」を整理し、「読んだ」を残し、「次の一冊」につなげる。

## 2. 想定ユーザー

初期リリースでは個人利用を想定する。

将来的には認証・複数ユーザー対応へ拡張できる設計とする。

## 3. 書籍ステータス

| ステータス | 意味 |
|---|---|
| Wishlist | 読みたい本 |
| Unread | 入手済みだが未読 |
| Reading | 読書中 |
| Paused | 読書を一時中断 |
| Completed | 読了 |

```text
Wishlist
   │
   │ 購入 / 借用
   ▼
Unread
   │
   │ 読書開始
   ▼
Reading
   │
   ├────→ Paused
   │         │
   │         └────→ Reading
   │
   │ 読了
   ▼
Completed
```

---

## 4. Wishlist

まだ入手していない本をWishlistとして登録できる。

### 管理項目

- タイトル
- ISBN
- 著者
- 出版社
- 発売日
- ページ数
- 表紙画像URL
- ジャンル
- 優先度
- メモ
- 知ったきっかけ
- Wishlist登録日

タイトルのみ必須とする。

- ISBN
- タイトル

- 出版社
- 発売日
- ページ数
- 説明文
- カテゴリ
- 表紙画像

外部APIから取得できない場合は手入力を可能とする。

## 10. 借用情報

返却期限は任意。

---

## 11. 返却期限管理

未返却かつ返却期限が設定されている本について期限状態を判定する。

### 通常

```text
Today < DueDate
```

### 返却期限間近

初期設定では3日以内。

```text
DueDate - Today <= 3 days
```

### 期限超過

```text
Today > DueDate
AND
ReturnedAt = null
```

## 12. 読書管理

### 中断

### 再開

### 読了

## 17. AI書籍レコメンド

AIのみで書籍を生成するのではなく、以下を組み合わせる。

```text
AI
+
Books API
+
ユーザー自身のBook DB
```

### 処理フロー

```text
現在読んでいる本
       ↓
書籍基本情報取得
       ↓
AIによる特徴抽出
       ↓
検索キーワード生成
       ↓
Books API検索
       ↓
実在する候補書籍を取得
       ↓
ユーザーのBook DBと照合
       ↓
AIによる順位付け
       ↓
おすすめ書籍を返却
```

### AIの責務

- 書籍特徴の抽出
- Books API検索キーワード生成
- 候補書籍の比較
- 推薦順位付け
- 推薦理由生成

### Source of Truthにしない情報

以下はAIを正としない。

- ISBN
- 正式タイトル
- 著者名
- 出版社
- 発売日

これらはBooks APIまたは自前DBを正とする。

---

## 18. 推薦候補と自前DB照合

以下を判定する。

- NotRegistered
- Wishlisted
- Unread
- Reading
- Completed

Completedは原則として新規推薦対象から除外する。

WishlistやUnreadに登録済みの場合は、状態を付与して返却する。

## 21. MVP完成条件

以下の一連の操作がBackend APIのみで成立すること。

```text
ISBNで本を検索
↓
Wishlist登録
↓
購入または借用
↓
積読へ移行
↓
読書開始
↓
読書ログ登録
↓
現在読んでいる本からAIおすすめ取得
↓
おすすめ本をWishlist登録
↓
元の本を読了
↓
借用本の場合は返却
↓
統計確認
```
